# GitHub upload instructions

1. Sign in to GitHub and create a new repository named `CSA04-192511053-Assignment1`.
2. Choose Private or Public according to faculty instructions. Do not upload real patient data or personal identifiers.
3. Extract this ZIP. Open a terminal in the extracted project folder.
4. Run:

```bash
git init
git branch -M main
git add .
git commit -m "Add assignment structure and initial OS design"
git remote add origin https://github.com/YOUR-USERNAME/CSA04-192511053-Assignment1.git
git push -u origin main
```

5. Replace `YOUR-USERNAME` with your actual GitHub username.
6. Commit task work progressively, for example:

```bash
git add Task05 Screenshots Evidence
git commit -m "Add system call implementation and evidence"
git push
```

7. Copy the actual repository URL into the Word report. The repository has not been created or uploaded automatically by this package.
