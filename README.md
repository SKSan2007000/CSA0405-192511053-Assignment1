## Project Overview

This repository contains the analysis, implementation and supporting materials for the CSA04 Operating Systems assignment based on a Smart Hospital environment.

It demonstrates operating-system concepts, system-level programming, process management, memory management, system calls, performance evaluation and operating-system design considerations.

## Installation and Setup

Update Ubuntu packages:

```bash
sudo apt update
```

Install the required tools:

```bash
sudo apt install -y build-essential git python3 strace time
```

Clone the repository:

```bash
git clone https://github.com/SKSan2007000/CSA0405-192511053-Assignment1.git
```

Navigate to the project directory:

```bash
cd CSA0405-192511053-Assignment1
```
