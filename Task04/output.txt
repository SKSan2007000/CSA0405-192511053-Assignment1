TASK 4 – Operating-system services matrix
Service | Monitor | Tablet | Workstation | Database
UI | Minimal display/alarm | Touch UI | Full GUI | Minimal admin UI
Program execution | Validated tasks only | Clinical apps | Clinical apps | DB engine
I/O | Sensor I/O | Touch/radio | Keyboard/display/network | Storage/network
File system | Small controlled config/logs | Encrypted app storage | Managed files | Durable DB files
Communication | Deterministic device links | Wi-Fi/API | Hospital LAN | Cluster replication
Error detection | Watchdog/sensor fault | App/radio errors | OS/app monitoring | DB/storage fault
Resource allocation | Fixed-priority scheduling | Power-aware | General scheduler | CPU/RAM/I/O controls
Accounting/logging | Safety event log | Device/audit logs | User audit | Transaction audit
Protection | Process/device isolation | App sandbox | RBAC | DB roles
Security | Secure boot/signed updates | MDM/MFA/encryption | EDR/MFA/patching | Encryption/backups

Monitor services to minimise: desktop shell, printing, media, unrelated daemons, unnecessary network listeners.
Never remove essential sensor I/O, watchdog, error detection, security, secure update or safety logging.
Database essentials: program execution, file/storage I/O, communication, error detection, resource allocation, audit, protection and security.
