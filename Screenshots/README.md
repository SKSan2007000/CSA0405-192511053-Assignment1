# Required personal execution screenshots
The assignment PDF requires screenshots of command outputs in GitHub. Capture real screenshots from your own Ubuntu/WSL2 terminal after running:
- Task05: `./run.sh` and `strace -c ./syscall_demo`
- Task06: `./run.sh`, `strace -c ./file_copy`, `/usr/bin/time -v ./file_copy`
- Task07: `./run.sh` and `./run_duplicate_output_experiment.sh`
- Task10: `./run_all.sh` and Task06 timing/strace measurements
- Tasks 1–4, 8–9, 11–12: `python3 main.py`
Save PNG/JPG files here with meaningful names, e.g. `Task06_strace.png`. These screenshots must come from your machine. The repository intentionally does not contain simulated terminal screenshots.
